# Pi Monthly Spending

A simple monthly spending tracker designed for the Pi ecosystem.

## Features

- Monthly spending overview
- Expense tracking
- Spending categories
- Monthly budget overview
- Payment method tracking
- Pi payment category
- Responsive design

## Current Version

The initial version stores expense data locally in the user's browser.

## Planned Features

- Pi Network authentication
- Vercel API
- Neon PostgreSQL
- Cloud-synchronized expenses
- User accounts
- Monthly budgets
- Pi transaction tracking
- Spending charts
- Export functionality

## Deployment

This project is designed to be deployed through Vercel.
