# Contributing

Thank you for considering an improvement to Pi Monthly Spending.

## Before opening an issue

- Search existing issues first.
- Describe the browser, device, steps to reproduce, expected result, and actual result.
- Use fictional sample expenses. Never include account numbers, credentials, or private financial data.

## Pull requests

Keep each change focused, preserve the local-first privacy model, and explain how you verified the change. UI changes should remain usable on both mobile and desktop screens.
