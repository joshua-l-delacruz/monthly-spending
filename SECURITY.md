# Security policy

## Supported version

Security fixes are applied to the current `main` branch and public deployment.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature under **Security → Advisories → Report a vulnerability**. Do not open a public issue containing Pi access tokens, API keys, signed cookies, payment identifiers, account numbers, real financial records, or exploitable details.

## Scope

Useful reports include authentication or session weaknesses, unauthorized payment behavior, exposure of locally stored financial records, missing input validation, unsafe dependency behavior, or claims in the UI that do not match the implemented data boundary.

The public premium purchase path is intentionally disabled until durable entitlements and complete analytics are implemented.
